# ThunderRanks

A simple and lightweight custom rank plugin for Paper Minecraft servers.

## Features

- 10 customizable ranks
- Persistent rank data
- Player self-rank selection
- OP/Admin rank management
- Rank reset system
- Rank-based chat colors
- Default rank: Noob
- Lightweight and easy to use

## Ranks

1. Owner
2. Co-Owner
3. Admin
4. Developer
5. Moderator
6. PvPer
7. Builder
8. Clutcher
9. Begger
10. Noob

## Commands

### Players

`/rank`

`/rank set <rank>`

`/rank reset`

`/rank help`

Players can choose from:

- PvPer
- Builder
- Clutcher
- Begger
- Noob

### Operators

`/rank set <player> <rank>`

`/rank reset <player>`

## Permission

`thunderranks.admin`

Default: OP

## Data

Rank data is stored in:

`plugins/ThunderRanks/ranks.yml`

## Requirements

- Paper
- Minecraft 1.21.x
- Java 21+
